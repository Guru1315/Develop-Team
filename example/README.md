# Example

A written sample of what the team returns for one request.

- **Input:** `Build a CLI to-do app in Python with add, list, and delete.`
- **File:** [`todo-app-output.md`](todo-app-output.md)

## What the final output contains

The final reply (Direct Reply in Flowise, Final Package in n8n) has four sections, in this order:

1. **Spec** from the Product Manager
2. **Design** from the Architect
3. **Code** from the Developer
4. **Test Report** from the Tester

## Status

`todo-app-output.md` is still a placeholder. To fill it in, run the flow with the input above and paste the final output into that file. Screenshots of a real run are in [`../Outputs/`](../Outputs/) and [`../Crew Workflows/`](../Crew%20Workflows/).
